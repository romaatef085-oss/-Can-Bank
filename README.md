1. Project Name: Can Bank

2. Project Idea: Can Bank is a motion graphics project that promotes environmental awareness and encourages recycling.
The project introduces smart recycling machines that collect empty plastic bottles and aluminum cans. Users can insert their containers into the machine, register their phone numbers, and receive rewards.
The main goal is to reduce plastic waste, encourage recycling, and contribute to a cleaner environment.
